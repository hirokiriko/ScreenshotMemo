# GENBA Search デモ（PoC / MVP）

現場用語・業界の会話語から、特許明細書中の「示唆表現」を抽出する概念類推型特許検索のデモページです。

すべてブラウザ内のダミーデータで動作し、サーバー・API は不要です。GitHub Pages でそのまま公開できます。

## GitHub Pages での公開手順

1. GitHub で新しい Public リポジトリを作成します。
   例: `genba-search-demo`
2. この `index.html` をリポジトリ直下に置いて push します。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Source: Deploy from a branch`、`Branch: main`、フォルダ: `/(root)` を選択して `Save` します。
5. 数分後、次の URL で公開されます。
   `https://<ユーザー名>.github.io/genba-search-demo/`
